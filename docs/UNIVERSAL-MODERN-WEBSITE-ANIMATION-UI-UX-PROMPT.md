# Universal Modern Website Animation & UI/UX Redesign Prompt

## Role

Act as a **senior product designer, UI/UX architect, motion designer, and frontend animation engineer**.

Redesign the existing application into a **premium, modern, highly polished, responsive, accessible, production-ready product experience**.

Do not treat this as a simple visual skin or a collection of animations.

Rework the **entire visual hierarchy, layout, component composition, interaction behavior, animation system, responsive behavior, empty/loading/error states, illustrations, and user journey** while preserving the application's existing business logic and functionality.

---

# 1. Primary Problem

Modern applications often rely on static interfaces that fail to communicate:

- System feedback
- User actions
- Navigation changes
- Content relationships
- Loading progress
- Data changes
- Success and failure states
- Important information hierarchy

A static interface can make a product feel disconnected, slow, and difficult to understand.

The redesigned application must instead feel **alive, responsive, intelligent, and intentional**.

Every important interaction should communicate:

> **What happened → What changed → What the user can do next.**

---

# 2. Primary Solution

Design a premium modern website/application that combines:

- Exceptional UI/UX
- Purposeful motion
- High-quality modern illustrations
- Carefully designed 3D visual elements
- Responsive layouts
- Elegant micro-interactions
- Smooth navigation
- Strong information hierarchy
- Fast perceived performance
- Accessibility
- Enterprise-grade reliability

The result should feel inspired by the polish of:

- Apple
- Linear
- Stripe
- Vercel
- Notion
- Framer
- Airbnb

but **must not blindly copy any of their interfaces**.

Create an original visual identity appropriate for the application's product, users, data, and business domain.

# 43. Motion Hierarchy

### Level 1 — Immediate feedback

100–250ms.

Use for:

- Button press
- Toggle
- Icon
- Hover

### Level 2 — Component transitions

250–450ms.

Use for:

- Cards
- Dropdowns
- Tabs
- Modals

### Level 3 — Page/section transitions

350–700ms.

Use sparingly.

The slower the animation, the more important the visual event must be.

# 65. Final Quality Bar

Before considering a screen complete, verify:

### Visual

- Is the hierarchy obvious?
- Does it feel premium?
- Are illustrations contextual?
- Are spacing and alignment consistent?
- Are colors controlled?

### UX

- Is the primary action obvious?
- Is the user's current context clear?
- Does every action provide feedback?
- Are empty/error states useful?

### Motion

- Does animation communicate something?
- Is it fast enough?
- Is easing consistent?
- Is reduced motion supported?

### Responsive

- Does it work on desktop?
- Tablet?
- Mobile?

### Accessibility

- Can it be used by keyboard?
- Are focus states visible?
- Is contrast sufficient?
- Are icon-only actions labeled?

### Performance

- Are animations GPU-friendly?
- Are images lazy-loaded?
- Are 3D assets optimized?
- Is unnecessary blur avoided?

```text
Every drawer
Every notification
Every loading state
Every empty state
Every error state
Every success state
Every mobile layout
Every navigation state
```

Use modern illustrations and 3D visuals wherever they improve comprehension or visual hierarchy.

Use animation wherever it improves:

- Navigation
- Feedback
- Hierarchy
- Perceived performance
- Context
- Engagement

Do not add animation merely because animation is available.

The finished product should look like a **high-end modern SaaS application designed by a senior product design team**, while remaining practical, fast, accessible, maintainable, and production-ready.
